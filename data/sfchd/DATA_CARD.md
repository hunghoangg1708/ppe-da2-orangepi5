# sfchd — Data Card

- **Full name:** SFCHD (Safety Clothing and Helmet Detection)
- **Source:** paper "Large, Complex, and Realistic Safety Clothing and Helmet Detection:
  Dataset and Method" (Yu et al., 2023) — `references/papers/sfchd_scale_2023yu.pdf`.
- **License:** not confirmed in the available documentation. Verify the original source
  before using this beyond personal research.
- **Scale per paper:** 12,373 Full HD/2K images, 50,552 annotations, from 40 surveillance
  cameras at 2 chemical plants. 3 lighting conditions: standard 68.2%, glare 11.4%,
  low-light 20.4%.
- **Actual scale in `raw/`:** 12,372 images, close to the paper's count (off by 1).
- **7 classes** (`raw/classes.txt`): `person, helmet, self_clothes, safety_clothes, head,
  blur_head, blur_clothes`.

## Split

The paper describes a 4:1 train:test split (9,898 / 2,475) — but **this download does not
include the original split file list** (no `train_files.txt`/`val_files.txt` like `sh17`,
no `train/valid/test` folders like `css`). So **the numbers here cannot be directly
compared against the paper's benchmark** (different test set).

`processed/` is generated by `scripts/data/prepare_sfchd.py`: a fresh **random 80/10/10
split, seed=42** (train 9897 / val 1237 / test 1238).
